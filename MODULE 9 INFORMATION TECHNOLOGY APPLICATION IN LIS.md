

`\\\ File Requirements for Acquisition ///`
  1. Vendor/Supplier File
      Details of book suppliers, publishers, distributors, & vendors.
      > Contents:
         Vendor ID, Vendor Name, Address, Contact, Supply terms, Specialization, Discount
         
  2. Bibliographic File
      Contains bibliographic details of documents proposed for acquisition.
      > Contents
         Author, Title, Edition, Publisher, ISBN, Price etc
  
  3. Recommendation File
      Stores recommendations received from faculty, researchers, students, or departments.
      > Purpose:
         Selection decision, Collection development
      > Contents:
         Recommender name, Department, Book details, Date of recommendation, Priority level
  
  4. Order File
      Maintains records of orders olaced with vendors
      > Purpose:
         Track pending orders, Monitor supply status
      > Contents:
         Order Number, Vendor Name, Order date, Price, Delivery Date

  5. Accession File
      Maintains records of documents received and accessioned.
      > Purpose:
         Permanent record of library holdings, Stock verification
      > Contents:
         Accession Number, Title, Author, Cost, Source

  6. Fund/Budget File
      Contains financial information relating to acquisitions.
      > Purpose:
         Budget monitoring, Financial control
      > Contents:
         Budget allocation, Department-wise funds, Expenditure details, Balance amount
      

  7. Invoice File
      Stores supplier invoice details.
      > Purpose:
         Verification of bills, Payment processing
      > Contents:
         Invoice number, Vendor name, Amount, Date, Payment status

  8. Claim File
      Maintains records of delayed or missing orders
      > Purpose:
         Follow-up of pending orders, Vendor accountability
      > Contents:
         Order Number, Vendor, Date of Clain, Response

  9. Standing Order File
      Maintains records of publications received automatically on a continuing basis.
      > Purpose:
         Ensure regular receipt of publications
      > Contents:
         Series title, Publisher, Frequency, Subscription details

`/// Types of Transmission Media \\\`
  > Guided (Bounded/Wired) Media
     Signals travel through a physical path.
   
   1. Twisted Pair Cable
       Used in telephone networks and LANs.
       Low cost.
       Eg: Telephone line.
   2. Coaxial Cable
       Higher bandwidth than twisted pair.
       Eg: Cable TV networks.
   3. Optical Fiber
       Uses light pulses for transmission.
       Very high speed and bandwidth.
       By Charles K. Kao
       Eg: Internet backbone networks.
   
  > Unguided (Unbounded/Wireless) Media
     Signals travel through air or space.

    1. Radio Waves
        By Marconi
        Radio broadcasting, Mobile communication
    2. Microwaves
        Line-of-sight communication.
        High-frequency transmission.
        Eg: Mobile towers, Long-distance communication
    3. Satellite Communication
        Uses artificial satellites as relay stations.
        Eg: INSAT satellites of ISRO



`/// Modes of Transmission Media \\\`
  Direction in which communication takes place between sender and receiver.

  > Simplex Mode
     Only in one direction.
     Receiver cannot send back information.
     Sender → Receiver
     Eg: TV, Radio

  > Half Duplex Mode
     Communication in both directions.
     Only one direction at a time.
     Sender ⇄ Receiver
      (One direction at a time)
     Eg: Walkie-talkie, Police wireless systems

  > Full Duplex Mode
     two-way communication.
     Both parties can send and receive at the same time.
     Sender ⇄ Receiver
      (Simultaneously)
     Eg: Telephone, Mobile phone, Video conferencing




`/// Components of a Telecommunication System \\\`
  1. Information Source (Sender)
      Human voice, Computer, Mobile phone, Digital document
  2. Transmitter
      Converts info into elec, optical, or radio signals.
      Modem, Telephone transmitter, Mobile handset
  3. Transmission Medium (Channel)
      Carries signals from source to destination.
      Fiber optic cable, Radio waves, Satellite link
  4. Receiver
      Receives signals and converts them back into usable info.
  5. Destination/User
      The final recipient of the information.
      Eg: Library user, Researcher, Organization
 
 6. > Protocol (Modern Component)
       Rules governing communication.
       TCP/IP, HTTP, FTP, SMTP
         



`/// Ethernet \\\`
  Widely used LAN technology for connecting computers and devices within a network.
  By Robert Metcalfe
  At Xerox PARC in 1973
  Maintained by
   Institute of Electrical and Electronics Engineers
  Standard Number: IEEE 802.3



`///// Network Interface Card \\\\\`
  Hardware component that enables a computer or device to connect to a network.
  AKA Network Adapter or LAN Card.

  - Connects computer to a network.
  - Converts data into network signals.
  - Sends and receives data packets.
  - Provides a unique MAC (Media Access Control) Address.

  > Types NIC
    1. Wired NIC
        Uses Ethernet cable (UTP/Fiber)
        Common in desktops & servers
    2. Wireless NIC
        Uses Wi-Fi signals.
        Common in laptops and smartphones.

   Works mainly at the `Physical Layer` and Data Link Layer of the OSI Model.

`///// Hub \\\\\`
  Basic networking device used to connect multiple computers in a network.
  Acts as a central connection point.
  Receives data from one device and broadcasts it to all connected devices.
  - Connects computers in a LAN.

  `Computer A → Hub → Sent to all computers`

  Replaced by Switches coz switches are more efficient.



`///// Router \\\\\`
  Networking device that connects two or more networks 
  and forwards data packets between them.
  Selects best path for data transmission.
  - Connects LAN to Internet.
  - Selects best path for data transmission.
  - Uses IP Addresses.
  - Controls traffic flow.

   `Home Network → Router → Internet`

   > Types
      Wired Router:  Uses Ethernet connections.
      Wireless:      Provides Wi-Fi connectivity.
      Core Router:   Used by large organizations and ISPs

   > OSI Layer
      Network Layer (Layer 3).





`///// Modem \\\\\`
  MOdulator + DEModulator
  Converts digital signals into analog signals and vice versa.
  Modulation:     Digital → Analog
  Demodulation:   Analog → Digital

  `Computer → Modem → Cable/Fiber Network → Internet`

   > Types
      Dial-up Modem: Traditional telephone modem.
      DSL Modem:     Uses telephone lines for broadband.
      Cable Modem:   Uses cable TV networks.
      Fiber Modem:   Used in optical fiber Internet cnctns.
   
   > OSI Layer
      Physical Layer (Layer 1).




`/// NETWORK TYPES \\\`

 > LAN
    Local Area Network
    Connects computers within a limited geographical area.

   - High Speed
   - Privately owned
   - Easy management

   > Common Technologies
      Ethernet (IEEE 802.3)
      Wi-Fi (IEEE 802.11)

   > LIS Application
      Koha server connected to library computers
      OPAC terminals within a library



 > MAN
    Metropolitan Area Network
    Connects multiple LANs across a city/metropolitan region.

   - Larger than LAN
   - Smaller than WAN
    Eg: University campuses, City-wide government networks

    > LIS Applications
       Public library branches within a city connected together



 > WAN
    Wide Area Network
    Connects networks across countries or continents.

   - Largest network type
   - Uses leased lines, fiber optics, satellites
   - Higher communication cost
    Eg: Internet, Banking networks

    > LIS Applications
       INFLIBNET Connectivity
       Access to international databases
       Digital library services



 > Wireless Network
    Uses radio waves or electromagnetic signals instead of physical cables.

   - Mobility, Easy expansion, Flexible installation
    Eg: Wi-Fi, Mobile networks, Bluetooth

    > Maintained by:
       Institute of Electrical and Electronics Engineers under IEEE 802.11.
    
    > LIS Applications
       Wireless OPAC access
       Mobile library services
       Access to e-resources through wi-fi







`/// NETWORK TOPOLOGIES \\\`
  Arrangement of computers, cables, & communication devices in a network.

  1. Bus Topology
      All devices are connected to a single communication cable called the bus

      `Computer ─ Computer ─ Computer ─ Computer` 
               (Single Backbone Cable)

      - Single transmission line
      - Data travels in both directoins
      - Terminators used at both ends
      - Low Cost, Easy installation, Less cable

      Eg: Early Ethernet networks


  2. Star Topology
      All devices connect to a central hub or switch.

                Computer
                   |
      Computer --Switch-- Computer
                   |
               Computer

      - Most common topology today
      - Centralized management
      - Easy troubleshooting, Easy expansion
      - Failure of hub/switch affects entire network
      - Requires more cable

      Eg: Modern Ethernet LANs.


  3. Ring Topology
      Each device is connected to two neighboring devices forming a closed loop.

      Computer ─ Computer
         |           |
      Computer ─ Computer

      - Data travels around the ring
      - Each node acts as a repeater.
      - Orderly data transmission
      - No collisions
      - Failure of one node can disrupt the network
      - Difficult maintenance

      Eg: Earlier IBM networking systems.


  4. Token Ring Topology
      A special form of Ring Topology where
      a token controls transmission.
      Dev by IBM in 1980s
      Only the computer `holding the token` can transmit data.

      `Token → Node → Node → Node → Node`

      - No data collision
      - Efficient traffic management
      - Expensive, Complex, Obsolete

      Standard: `IEEE 802.5`


  5. Mesh Topology
      Each device is connected to every other device.
      - Multiple communication paths
      - Reliable, No single point of failure
      - Expensive, Complex wiring
      Eg: Military and mission-critical networks.

`/// LAN: Types \\\`
 1. Wired LAN
     Devices are connected through physical cables.
     High speed
     Better security
     Reliable communication
     Eg: Library computers connected through Ethernet cables.

     > Media Used
        UTP, STP, Coaxial Cable, Optical Fiber

     > Technology
        Ethernet (IEEE 802.3)

 2. Wireless LAN (WLAN)
     Devices communicate using radio waves instead of cables.
     Mobility, Easy intallation, Flexible expansion
     Lower security, Signal interference
     Eg: Wi-Fi-enabled library network.

     > Technology
        Wi-Fi

     > Standard
        IEEE 802.11

 3. Client-Server LAN
     One or more dedicated servers provide services to client computers.
     - Centralized control
     - Better security
     - Efficient resource management

     > Examples
        Koha server providing OPAC services
        Library database server

     > LIS Application
        Most modern library automation systems

 4. Peer-to-Peer (P2P) LAN
     Every computer can act as both client and server.
     - No dedicated server
     - Easy to set up
     - Suitable for small networks
     - Low cost, Easy management
     - Limited security, Difficult administration
     
     > Example 
         Small office network with a few computers sharing files.

`//// DSL \\\\`
  Digital Subscriber Line 
  Broadband technology that provides high-speed Internet access through existing copper telephone lines.

  > Types
   1. ADSL
      Asymmetric DSL
      Download speed greater than upload speed.
      > Suitable for:
        Home users, Students, General Internet browsing 
   2. SDSL
      Symmetric DSL
      Equal upload and download speeds.
      > Suitable for:
        Business, Servers
   3. VDSL
      Very High Bit Rate DSL
      Much higher speed than ADSL.
      Suitable for multimedia applications.




`/// Internet Protocols \\\`
  Set of rules and standards that govern communication between computers and devices on a network.

  1. FTP
    Standard network protocol used for transferring files. Between computers over a TCP/IP network such as the Internet.

    `Client ↔ FTP Server`

    - File uploading
    - File downloading
    - Directory management
    - Remote file access
    > Default Port
       Port 21 (Control Connection)
    > Types
       Anonymous FTP, Authenticated FTP

  2. HTTP
    HyperText Transfer Protocol
    Standard protocol used for transferring web pages & other resources on the World Wide Web.
    Dev by Tim Berners-Lee @ CERN

    `Browser ↔ Web Server`

    - Supports hypertext docs
    - Foundation of the World Wide Web.
    - Client-server communication.
    - Platform independant

    Enable communication between:
      Web Browser (Client)
      Web Server
    > Default Port
       Port 80
    > Methods
       GET:    Retrieve Information
       POST:   Send information to server
       PUT:    Update information
       DELETE: Delete information

  3.  HTTPS
     HyperText Transfer Protocol Secure
     > Default Port
        Port 443
     > Security
        Uses SSL/TLS encryption
      

   4. TCP/IP
      Transmission Control Protocol / Internet Protocol
      Fundamental communication protocol suite of the Internet
      `Rules` that allow computers and networks worldwide to `communicate and exchange data`
      By Vinton Cerf, Robert E.Kahn
      1970s
      Adopted on 1 Jan 1983

      `TCP`:
        Reliable data delivery
        Error checking and sequencing
      `IP`:
        Addressing and routing
        Packet forwarding

      > TCP/IP Layer Model
         1. Application Layer
         2. Transport Layer
         3. Internet Layer
         4. Network Access Layer

         Application Layer
                ↓
         Transport Layer (TCP/UDP)
                ↓
         Internet Layer (IP)
                ↓
         Network Access Layer

      > Applications of TCP/IP
         E-mail, File Transfer, VIdeo Conferencing, Cloud Computing, Library Networks

      > TCP/IP in Libraries
         Koha Web OPAC, DSpace repos, e-Granthalaya

   

   5. SMTP
      Simple Mail Transfer Protocol
      Standard Internet protocol used for sending e-mail
      Application-layer protocol
      For sending mail, not retrieving mail.

      Sender
         ↓
      Mail Client
         ↓ SMTP
      Outgoing Mail Server
         ↓
      Internet
         ↓
      Recipient Mail Server
         ↓ POP3 / IMAP
      Receiver

      > SMTP Ports
         Standard SMTP:          Port 25
         Secure SMTP Submission: Port 587
         SMTP over SSL/TLS:      Port 465

   
   6. POP3
      Post Office Protocol V3
      For receiving e-mails from a mail server to a user's computer or email client.

      - Retrieve e-mails from a mail server
      - Download messages to a local device.
      - Read e-mails offline after download.

      Mail Server
            ↓ POP3
      Email Client
            ↓
      User Reads Mail

      > POP3 Ports
         Standard POP3:          Port 110
         Secure POP3S:           Port 995
   

   7. IMAP
      Internet Message Access Protocol
      For accessing and managing e-mail messages directly on a mail server.
      Accesses and synchronizes e-mails

      Allows users to view and manage emails without downloading

      - Server-Based Storage
      - Multi-Device Access

      Mail Server
         ↕ IMAP
      Laptop
         ↕
      Smartphone
         ↕
      Tablet

      > POP3 Ports
         Standard IMAP:          Port 143
         Secure IMAPS:           Port 993
