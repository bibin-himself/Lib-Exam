`//Five Laws of Library Science//`

> Books are for use

- Focus is on the book

A library’s success is measured by how often its shelves are emptied by readers.

- Supporting elements
 Library Staff, Library building, Library Location, Library hours, Book selection, Shelf arrangement, Reference Service, Maintenance, 



> Every reader his/her book

- Focus is on reader

- Books are for everyone — not just scholars, but also the poor, sick, blind, prisoners, elderly, minorities, and disadvantaged groups.

Supporting Elements:
Library Legislation, Book Selection, Shelf arrangement, Cataloguing, Maintenenace, Reference Service, Resource sharing, Open Accessz


> Every book its reader

- Focus is on the book

- Libraries should ensure materials reach the right audience

Supporting Elements:
 Book selection, Cataloguing, Open access, shelf arrangement, OPAC, Exhibition


> Save the time of the reader

- Readers are busy people; libraries must be organized to minimize effort and maximize efficiency.

- Modern technology - OPAC, OCLC databases, computerized circulation, networking

Supporting Elements:
 Library services, Cataloguing, Open access, shelf arrangement, OPAC, Cenralised cata and classi, Reference Librarian, SIgnage System, Publicity


> Library is a growing organism

- a social institution that grows continuously like a living organism

- Growth occurs in documents, readers, staff, services, and technology.

Supporting Elements:
 Classification scheme, Shelf arrangement, Catalogue code, reference service, user edu, Staff

`// Kerala Public Libraries Act, 1989 \\`

 Provide a statutory framework for public libraries in Kerala

 Inspired by P.N. Panicker and the Kerala Granthasala Sangham.

 Free and equal access to library services

> Key Provisions

  - Kerala State Library Council as the apex body.
  - District Library Councils and Local Library Committees form the network

  - State Central Library → District Libraries → Taluk Libraries → Branch/Village Libraries.
  - Integration of existing libraries into a unified system.

  - Funded through government grants, 5% of building/property tax, RRRLF


`Kerala State Library Council`
