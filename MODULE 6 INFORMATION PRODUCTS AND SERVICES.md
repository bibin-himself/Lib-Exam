`// Types \\`  

> Robert Taylor's Four Levels
  By Robert S. Taylor
  Focuses on `how a need evolves in the user's mind` before they express it.

  `VCFC`

  1. Visceral Need:
      A vague, subconscious feeling that something is missing.
      Eg: A student feels confused but cannot identify exactly what information is required.

  2. Consious Need: 
      User becomes aware of the information requirement.
      They describe their knowledge gap.

  3. Formalized Need:
      Need is expressed clearly.
      The user can clearly articulate the need in a spoken sentence to others.

  4. Compromised Need:
      Need is translated into a form suitable for an information system.
      Eg: Search query to a database




> Krikelas Model
   1983
   By James Kirkelas
   Information need arises from uncertainity
   Information is sought to reduce uncertainty.

   `Core Concepts:`
      Information Need:    Unceratinity  arises
              ↓
      Information Seeking: Searching for information
              ↓
      Information Source:  Destination where the user looks
              ↓
      Information Use:     Application of found data
   
   `2 Types of Needs`
     Immediate Needs:
      Info Seeking
      Triggered by a specific, current problems.
     Deferred Needs:
       Info Gathering
       Triggered by general background interest or anticipation of future problems.


> Wilson's Model of Information Need
   By Thomas D. Wilson
   1981
   Heavily revised in 1996
   Information need is `influenced by personal, social, and environmental factors`.
   Foundational framework of modern information science.

    "information need" is not a primary human need.
    Byproduct of a person trying to satisfy a deeper, more fundamental primary need.

   `3 Fundamental Primary Need`
      1. Psychological Needs:
          Basic survival demands
          eg: searching for medical info when sick
      2. Cognitive Needs:
          The intellectual desire to understand, learn, or master a concept.
          eg: researching a complex topic for a class
      3. Affective Needs:
          Emotional or psychological desires,like seeking validation, reducing anxiety etc



> Kuhlthau's Information Search Process (ISP) Model
   1991
   By Carol C Kuhlthau
   Info seeking is not only a cognitive activity but also involves:
    Feelings (affective)
    Thoughts (cognitive)
    Actions (physical)

   `6 Stages - ISEFCP`
     1. Initiation
         User realizes a lack of knowledge or information.
        Feelings: Uncertainty, Apprehension, Confusion
        Thoughts: General awareness of a problem
        Actions:  Seeking background info

     2. Selection
         User selects a topic or problem area.
        Feelings: Optimism, Hope
        Thoughts: Possible approaches are considered
        Actions:  Choosing a general topic

     3. Exploration
         User investigates information on the topic.
        Feelings: Confusion, frustration, Doubt
        Thoughts: Info appears inconsistent
        Actions:  Reading broadly from various sources
      
     4. Formulation
         User develops a focused perspective
        Feelings: Increased confidence, Clarity
        Thoughts: Topic becomes clearly defined
        Actions:  Formulating a precise info need

     5. Collection
         User gathers relevant information.
        Feelings: Confidence, Interest
        Thoughts: Focused understanding develops
        Actions:  COllecting useful info systematically

     6. Presentation
         Search is completed and results are presented.
        Feelings: Relief, Satisfaction
        Thoughts: Evaluation  of completed task
        Actions:  Writing reports, assignments,research papers
         


> Belkin's ASK Model
   1980
   Nicholas J. Belkin
   Anomalous State of Knowledge

   - Information need arises because users `recognize deficiencies in their knowledge`.
   - Users often `cannot precisely specify` what information they `require`.
   - Widely used in information retrieval and search systems.

  > Structure
     `Problem/Situation`:
      User cannot articulate the exact need
            ↓
     `ASK`:
      Analyzes the structural "gap" in the user's concept
            ↓
     `Info Retreival System`:
      Analyzes the structural "gap" in the user's concept
            ↓
     `Info Presentation`:
      Matches documents that bridge the specific cognitive anomaly

`//// REFERENCE SERVICE \\\\`
  Providing personal assistance to users to search for info.
  Samuel Green first formalized the concept 
  In 1876

  `// Types of RS \\`
  1. Ready Reference:
      Fast, factual assistance that can be resolved in a few minutes.
      Uses Almanacs, Dictionaries, Encyclopedias, web search
  2. Long-Range Reference:
      In-depth research support for academics, scientists, or professionals.
      Searchs in multiple DBs,cross-referencing materials
  3. Digi/Virtual Reference:
       Asynchronous or real-time assistance provided via email, live chat software, SMS, or video calls.
       No need of physical lib visit

  Scholar	              Definition Focus
  James I. Wyer	        Assistance in using library resources
  Margaret Hutchins	     Direct personal aid
  Samuel Rothstein	     Personal assistance in pursuit of info
  S. R. Ranganathan	     Right reader and right book




`/// Reference Interview \\\`
  Communication process between a librarian and a user
  To identify, clarify, understand the user's info need
  So that accurate information can be provided.

  > Steps
   1. Establish Rapport: 
       Create a friendly and welcoming environment.
   2. Identify the Info Need:
       Understand what the user actually wants.
   3. Clarify the Query
       Remove ambiguity
   4. Verify the need:
       Confirm that llbrn has correctly understood the query.
   5. Search for Information:
       Select suitable sources and search strategies
   6. Present Information:
       Provide the information in an understandable form.
   7. Follow-Up
       Ensure the user's need has been satisfied.



`/// Search Techniques \\\`
  Methods used to retrieve relevant information efficiently From catalogues, DBs, search engines, information systems.

  1. Keyword Search
      Searching using significant words from a topic.
      Simple and widely used.
  2. Subject Search
      Searching using standardized subject headings.
      Eg: LCSH
  3. Author Search
      Searching by author's name
  4. Boolean Search
      Uses logical operators.
        AND: Narrows search
        OR : Broadens search
        NOT: Excludes unwanted terms.
  5. Title Search
      Searching by title of a document.
  6. Phrase Searching
      Searching exact phrases using quotation marks.
      Retrieves exact phrase only.
  7. Truncation
      Searching different word forms using symbols.
      Eg:Librar*
       Retrieves: Library, Libraries, Librarian
  8. Wildcard Searching
      Substitutes characters within words.
      Eg: Wom?n
       Retrieves: Woman, Women
  9. Field Searching
      Searching within specific database fields.
      Eg: Author = Ranganathan
 10. Citation Searching
      Searching documents through cited references.
      Uses: Literature review, Research tracking

`/// CAS \\\`
  Current Awareness Service
  Keep users informed about recent developments.
  Alert users to newly published literature.

  > Types
     1. General CAS: Information sent to all users.
     2. Subject-Oriented: Related to a specific subject area
     3. Electronic CAS: Provided through digital technologies.

  > Steps
     1. Review/Scan Docs
     2. Select Relevant Information
     3. Notify Users



`/// SDI \\\`
  H.P. Luhn
  Current Awareness Service 
  Relevant info, less noise
  `SDI = User Profile + Document Profile`
     Organize → Match → Notification → Feedback → Profile Revised  
  
  > 7 Steps of SDI
     1. Organize library on KEY-WORD system
     2. Users profile interests (kywd from thesaurus) → stored in computer
     3. Incoming documents analyzed & indexed (same kywd lang)
     4. User profile MATCHED with document profile
     5. CLOSE MATCH → User gets NOTIFICATION
     6. User provides FEEDBACK on relevance
     7. Profile ADJUSTED based on feedback (continuous revision)

  > 3 Operational Steps
     1. Creation of Database (Document Profile)
     2. Profile Construction
     3. Searching for Information
