

`/// Charging Systems \\\`
  Method used to record the issue and return of library materials.


`// Types \\`
 
 1. Browne Charging System
     By Nina E. Browne
     Uses borrower tickets and book cards
    > Procedure
     1. Each borrower receives `borrower tickets`.
     2. Each book contains a `book card`.
     3. `At issue`, book card & borrower ticket `filed together`.
     4. On return, cards are separated.

 2. Newark Charging System
     By Newark Public Library
     Uses borrower cards and book cards.
     > Procedure
      Uses:
       Borrower's card, Book Card, Date Slip
      Records are maintained systematically for circulation control.
      - Time-consuming.
      - Requires more paperwork.

 3. Ledger System
     Issue transactions are recorded in a ledger register.
     - Permanent record.

 4. Photo Charging System
     Borrower's card and book card are photographed together.
     - Faster than manual systems.
     - Requires photographic equipment.

 5. Token Charging System
     Users receive numbered tokens corresponding to borrowed items.
     - Simple
     - Limited applicability.

 6. Automated Charging System
     Uses: Computers, Barcodes, RFID
     Software Examples: Koha, e-Granthalaya
      - Fast processing, Real-time circulation status.
      - Requires infrastructure, Initial cost may be high





`/// Serial Control \\\`

`/// Kardex System \\\`
  A visible card system used for recording receipt of serial publications.
  - Tracks issues received.
  - Identifies missing issues.
  - Monitors subscriptions.

`/// Methods of Display \\\`
  
  1. Display Rack
      Most common method.
      Current issue displayed openly.

  2. Sloping Shelves
      Latest issue visible.
      Older issues stored behind.

  3. Newspaper Stands
      Used for newspapers.



  
`/// Standards for Space Estimation \\\`
  > Reader Space
     Approximately 25–30 sq. ft. per reader.
  > Staff Space
     Approximately 100–150 sq. ft. per staff member.
  > Book Storage
      Accepted standard is 10 to 15 volumes per square foot.
